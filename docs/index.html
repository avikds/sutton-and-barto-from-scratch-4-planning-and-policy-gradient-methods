Sutton and Barto from Scratch 4: Planning and Policy-Gradient Methods

How it was built

Part 1: Dyna-Q on the Maze

Encode the book's 6x9 maze, write tabular epsilon-greedy selection and the Q-learning update, learn a deterministic model from experience, add n planning updates per real step, and compare steps per episode for 0, 5 and 50 planning steps.

Part 2: When the Model Is Wrong and Prioritized Sweeping

Give the model a visit clock and untried actions, add the Dyna-Q+ exploration bonus kappa*sqrt(tau) in planning, run Dyna-Q and Dyna-Q+ through the blocking maze whose wall moves, then replace uniform replay with a priority queue keyed by the update magnitude and count how many updates prioritized sweeping needs to find the optimal path.

Part 3: REINFORCE on the Short Corridor

Build the short corridor with switched actions, parameterise a softmax policy with one preference per action, derive the exact value of any right-probability in closed form, then train REINFORCE with gamma^t weighting and REINFORCE with a learned baseline toward the optimal right-probability of about 0.59.

Part 4: Actor-Critic

Replace the Monte Carlo return with a one-step TD error from a learned critic on the corridor, then build the access-control queuing task, write the differential semi-gradient Sarsa update with an average-reward estimate, run it, and read off the accept/reject policy table of Figure 10.5.
